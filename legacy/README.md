# Legacy code

This directory contains code from earlier versions of the project. It is kept in
the repository as historical and implementation context for maintainers and
coding agents.

The files here are reference-only:

- They are not part of the supported `mmc_nirs` package API.
- They may depend on unavailable data, software, or outdated interfaces.
- They are excluded from automated formatting and lint checks.
- New package code should not import from this directory.

Legacy functionality may be redesigned and moved into the supported package in
future feature branches.
